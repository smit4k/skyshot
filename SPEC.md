# Skyshot rendering reference

Skyshot renders the selected post from the logged-out Bluesky web detail view, initially based on [Bluesky web 1.139.0, revision c85e67b](https://github.com/bluesky-social/social-app/tree/c85e67b62082df8a2b0a45640298f18e8c48ce3d). [Xeet](https://github.com/rauchg/xeet) informed the separation between resolution, layout, and paint.

| Area | Rules and reference |
| --- | --- |
| Post frame | 16 px gutters, 42 px avatar, 16.9 px body text with a 22 px line box, 13.1 px timestamp, compact stats, and static controls drawn from the [MIT-licensed Bluesky icon paths](packages/skyshot/LICENSE-Bluesky-icons). The optional ancestor context follows the compact thread layout. See [selected post](https://github.com/bluesky-social/social-app/blob/c85e67b62082df8a2b0a45640298f18e8c48ce3d/src/screens/PostThread/components/ThreadItemAnchor.tsx). |
| Text | Inter Variable, explicit Noto fallback by script, Unicode wrapping, bidirectional shaping, and color emoji. Valid UTF-8 facets color mentions, links, and tags. HTTP(S) display links retain the host and shorten long paths. Emoji-only posts use the 1.85 size multiplier. See [rich text](https://github.com/bluesky-social/social-app/blob/c85e67b62082df8a2b0a45640298f18e8c48ce3d/src/components/RichText.tsx) and [facet lexicon](https://github.com/bluesky-social/atproto/blob/main/lexicons/app/bsky/richtext/facet.json). |
| Media | Single images use the supplied aspect ratio within layout bounds. Two to four images use a grid. Gallery views with five or more items show the initial carousel and its page indicator. Video and GIF previews use a static poster. See [image embed](https://github.com/bluesky-social/social-app/blob/c85e67b62082df8a2b0a45640298f18e8c48ce3d/src/components/Post/Embed/ImageEmbed.tsx) and [gallery schema](https://github.com/bluesky-social/social-app/blob/c85e67b62082df8a2b0a45640298f18e8c48ce3d/lexicons/app/bsky/embed/gallery.json). |
| Record embeds | Support one quote with media, quote plus separate media, deleted/blocked/detached quotes, and cards for feeds, lists, and starter packs. Labeler records are skipped as in the pinned client. External cards and players use AppView's existing thumbnail and metadata. See [embed dispatch](https://github.com/bluesky-social/social-app/blob/c85e67b62082df8a2b0a45640298f18e8c48ce3d/src/components/Post/Embed/index.tsx). |
| Visibility | The resolver uses AppView without authentication. Global hide, warn, takedown, login-required and built-in adult labels suppress post content. Sensitive media stays hidden. Blocked or missing records use a tombstone. Visibility is applied before asset discovery. See [AT Protocol labels](https://atproto.com/specs/label) and [logged-out preferences](https://github.com/bluesky-social/social-app/blob/c85e67b62082df8a2b0a45640298f18e8c48ce3d/src/state/queries/preferences/const.ts). |

The host resolves handles and fetches the post from the public AppView. It fetches only approved Bluesky media URLs with redirects disabled. The web host resolves CDN image blobs through the PLC directory and retrieves them from Bluesky-hosted repositories that allow cross-origin reads. Images from self-hosted repositories still depend on whether their media URL allows cross-origin fetching. The known video thumbnail route maps to the official CDN directly. Offline inputs may provide bytes for any URL without triggering a fetch. Limits include 2 MiB post JSON, 8 MiB per encoded image, 32 MiB total encoded images, 16 million pixels per decoded image and output, and up to three ancestors.

Browser captures are a development reference. Skyshot uses English labels. The CLI and JavaScript wrappers default to the host time zone. The Rust library defaults to UTC. Operating system glyphs, experimental controls, dynamic link cards, and thread numbering can differ from the web app. The test matrix covers native/WASM parity. The controlled Chrome oracle checks line breaks and text-card geometry, with known differences recorded explicitly; it does not establish pixel parity with Chrome. See [PERFORMANCE.md](PERFORMANCE.md) for scope and current results.

Font sources, versions and SHA-256 hashes are pinned in [fonts/manifest.json](fonts/manifest.json). The Inter license is included in source. Downloaded fallback packs retain their corresponding OFL notices.

Current measurements, startup costs and core/font sizes are recorded in [PERFORMANCE.md](PERFORMANCE.md) and reproducible with `npm run bench`. Results depend on the host and whether the renderer's caches are warm.

Development captures measured a public [image post](https://bsky.app/profile/bsky.app/post/3n2m24be4e223) and [portrait video post](https://bsky.app/profile/bsky.app/post/3n2opitxdyc2j) at a width of 390 px. Their Skyshot outputs matched the Chrome crops' outer dimensions (390 × 784 and 390 × 758 respectively). A desktop text reply also matched the reference's body line count, with different word breaks and an added replying-to line.
